# Maaddism Productions

The website for Graveyard Night, published at https://grabhive.github.io

- `index.html`: home page
- `privacy.html`: the privacy policy that Google Play links to

The files are generated from the game project (GrabHive/graveyard-night, folder `website/`), so the policy always matches the copy inside the game. Change them there, then copy them here.
